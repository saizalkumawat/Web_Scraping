# 📚 PRODIGY_SD_05 - Web Scraping using Python

## 📌 Objective

Develop a Python program that extracts product information such as book names, prices, and ratings from an e-commerce website and stores the data in a CSV file.

---

## 🌐 Website Used

Books to Scrape

https://books.toscrape.com/

---

## 🚀 Features

- Extracts Book Name
- Extracts Price
- Extracts Rating
- Saves data into CSV format
- Displays extracted data

---

## 🛠 Technologies Used

- Python
- Requests
- BeautifulSoup (bs4)
- Pandas

---

## 📂 Project Structure

```
PRODIGY_SD_05/
```

## ⚙ Installation

Clone the repository

```bash
git clone https://github.com/saizalkumawat/Web_Scraping.git
```

Move into the project directory

```bash
cd Web_Scraping
```

Install dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Program

```bash
python web_scraping.py
```

---

## 📊 Output

The program generates:

```
books_data.csv
```

containing:

- Price
